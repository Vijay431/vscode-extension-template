# Say Hello

Open the **Command Palette** (`Ctrl+Shift+P` / `Cmd+Shift+P`) and run **Hello World** to verify your extension is active.

This command is the starter pattern for all commands in **{{DISPLAY_NAME}}**. Copy `HelloWorldCommand.ts`, rename it, and wire it up in `CommandsManager.ts` to add your next feature.

[Run Hello World](command:{{EXTENSION_ID}}.helloWorld)
